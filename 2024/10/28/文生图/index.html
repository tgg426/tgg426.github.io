补充：CogView-4模型

CogView-4 是智谱AI的图片生成模型，支持：

  • 文本描述生成图片
  • 高质量的图片生成
  • 中文理解能力强

PS: 智谱AI图片生成参数

详细参数说明请参考：智谱AI CogView-4 官方文档

支持的参数

参数 类型 说明 可选值
model string 模型名称 “cogview-4”
prompt string 图片描述 任意文本
n number 生成图片数量 1-4（默认1）
size string 图片尺寸 “1024x1024”, “512x512”
quality string 图片质量 “hd”, “standard”
